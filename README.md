## Cấu trúc thư mục

```text
pages/      → các trang HTML theo vai trò
assets/     → images / icons / data (JSON giả lập)
css/        → style.css, responsive.css
js/         → main.js, api.js, modules/
docs/       → tài liệu phân tích, bảng kiểm kê màn hình, khai báo AI
design/     → link + mockups Figma/Canva
```
